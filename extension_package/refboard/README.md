# RefBoard

RefBoard adds a dedicated node tree for arranging image references directly inside Blender's Node Editor.

## Features

- Drag and drop image files into a RefBoard node tree.
- Add single image nodes from the sidebar.
- Arrange selected image nodes as a row, column, or automatic grid.
- Match selected image widths or heights to the active image node.
- Control image draw order with per-node Z values.

## Supported Images

RefBoard currently accepts:

- PNG
- JPG / JPEG
- TGA
- BMP
- EXR
- WEBP

## Usage

Open a Node Editor, switch to the RefBoard node tree type, then use the RefBoard sidebar tab or drag image files into the editor.
